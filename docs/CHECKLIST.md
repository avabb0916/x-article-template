# 发布前自检清单

复制到你的待办里，每次发稿前过一遍。

## 内容

- [ ] 标题 ≤40 字，能独立看懂
- [ ] 全文只有 1 个 `#` 一级标题
- [ ] 二级标题 ≥5 个，且都是判断句不是名词短语
- [ ] 字数 ≥2000
- [ ] 全文只有一个 takeaway，且在前 300 字内出现
- [ ] 「不是X，是Y」≤3 次（AI 味最强信号）
- [ ] 保留 1–2 处真实犹豫（"我没验证过"）
- [ ] 结尾有一句提问

## 平台适配

- [ ] 没有表格（会被丢弃）
- [ ] 没有代码块（会被丢弃）
- [ ] 没有三级标题（会被降级）
- [ ] 没有加粗（多数平台文章接口不接受 inline style）

## 配图

- [ ] 5–9 张，每张只讲一个结构
- [ ] 每张图文件存在、路径正确
- [ ] 封面比例正确（X 文章 = 5:2）
- [ ] 封面关键信息在裁切安全区（feed 会再按 1.91:1 裁一次）
- [ ] 图里没有文字（中文由本地渲染叠加）

## 合规

- [ ] 没有外链、微信号、二维码（或已换成官方入口）
- [ ] 没有敏感词面（成人/赌博/翻墙…即使否定语境也可能被召回）
- [ ] 效果数字带来源或样本说明
- [ ] 没有绝对化承诺（全网第一 / 永久有效）
- [ ] 没有未公开的项目名 / 域名 / 关键词

## 自动检查

```bash
node scripts/check.mjs posts/*.md
```

`0 error` 才算过。CI 会在 push 时自动跑。
